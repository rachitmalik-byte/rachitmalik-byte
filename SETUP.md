# Upload this GitHub profile to your account

This bundle contains a ready-to-use README.md and original animated/design assets.

1. Sign in to GitHub and open your public profile repository named exactly **rachitmalik-byte**. If it doesn't exist, create it at https://github.com/new, set the repository name to `rachitmalik-byte`, choose **Public**, and tick **Add a README file**.
2. Open that repository, choose **Add file → Upload files**, and upload the **assets** folder with all six files. GitHub's web uploader may not preserve an empty folder, so select the actual six files and ensure they end up under an `assets/` directory. An easier method is to open the repo in GitHub Desktop and copy this folder into it, then commit and push.
3. Open `README.md`, click the pencil icon, replace all content with the included README.md, and **Commit changes**.
4. Check the **Preview** tab and then your profile at https://github.com/rachitmalik-byte.
5. OPTIONAL: replace the conceptual project-cover images with real screenshots or videos. Avoid treating concept art as a screenshot of the application.

### To upload assets reliably in the browser without Git
Open your profile repository and navigate to `assets` if already present. If not, create a file using **Add file → Create new file**, type `assets/.gitkeep` as its name, enter any text, and commit. Now open the `assets` directory and use **Add file → Upload files** to upload the six assets from this bundle.

### Notes
- GIFs may animate more slowly on some devices. Images still communicate the idea as static frames.
- GitHub READMEs don't run JavaScript or custom CSS. The layout uses Markdown and safe HTML.
- All animations are self-hosted in your GitHub repository — no third-party image service required.
- For best proof of implementation, include real screenshots, feature descriptions, and test information in each **project's own README**.
